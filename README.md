# Мастерская украшений "Lumina"

Краткое описание: Адаптивный сайт-визитка для мастерской украшений ручной работы. Реализована галерея товаров с фильтрацией, сохранение избранного в LocalStorage, переключение темной/светлой темы и валидация формы заказа.

## Ссылка на Netlify
[Открыть сайт](https://fascinating-stroopwafel-316926.netlify.app/) *(замените на свою ссылку)*

## Как запустить проект локально
1. Склонируйте репозиторий: `git clone https://github.com/ВАШ-НИК/ИМЯ-РЕПОЗИТОРИЯ.git`
2. Перейдите в папку проекта.
3. Откройте файл `index.html` в любом браузере (двойным кликом).
